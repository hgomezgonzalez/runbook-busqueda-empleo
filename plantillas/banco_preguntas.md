> Prepara **3 historias** y comprueba que cubren casi todas las preguntas de este bloque.

### Historia 1 — [PROYECTO DIFÍCIL QUE SACASTE ADELANTE]
```

R: [resultado con cifra]
```

### Historia 2 — [CONFLICTO O PRESIÓN]
```
S: · T: · A: · R:
```

### Historia 3 — [ERROR DEL QUE APRENDISTE]
```
S: · T: · A: · R:
```

**Preguntas que se responden con estas historias:**
- Háblame de un proyecto complejo → *Historia 1*
- Un desacuerdo con un compañero o jefe → *Historia 2*
- Un error que cometiste → *Historia 3*
- Cómo manejas la presión o un plazo imposible → *Historia 1 o 2*
- Una decisión difícil → *Historia 1*
- Cómo priorizas con recursos limitados → *Historia 1*
